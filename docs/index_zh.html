ZipRepairTool。

正常的压缩包修复工具：修复在传输过程中损坏的压缩包——附带全面的完整性检查，让任何解压软件都能重新打开。

⬇ 下载 JAR（v1.0） GitHub 仓库

01为什么有的压缩包打不开

在传输过程中损坏的压缩包元数据互相矛盾：它们的中央目录与本地文件头元数据不一致（文件名被改写、大小/CRC-32 被修改、伪目录条目、伪造的 EOCD 签名）。严格校验的解压软件——7-Zip、WinRAR、Windows 资源管理器、Python 的 zipfile——会拒绝它们，而基于 JVM 的应用依然能正常读取，因为 java.util.zip.ZipFile 信任中央目录。某些损坏的压缩包还会破坏文件内容本身（PNG 块 CRC-32 / IDAT Adler-32、Ogg 头部字段、被压缩成单行的 JSON）。

02功能

  • 检查——全面检测：条目数、本地头与中央目录元数据差异（文件名、大小、CRC）、伪目录、伪造 EOCD、数据 CRC-32 校验、无法读取的条目——并给出 完好 / 已损坏 的结论。
  • 修复——通过 ZipFile + ZipOutputStream 重建干净压缩包；输出的压缩包任何解压软件都能打开。它还会修复损坏的 PNG / Ogg / JSON 内容，让提取出的文件能再次打开。

03使用方法

java -jar ZipRepairTool.jar                              # 图形界面（检查 / 修复）
java -jar ZipRepairTool.jar -check <输入.zip>
java -jar ZipRepairTool.jar -repair <输入.zip> <输出.zip>

界面语言跟随系统（中文 / 英文）；命令行输出为英文。需要 JDK 8 或更高版本。
