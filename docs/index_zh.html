我的世界资源包反混淆工具。

反混淆被 PackSquash 等工具混淆或保护的 Minecraft 资源包（mcpack）——附带完整的完整性检查与可调参数的混淆模式。

⬇ 下载 JAR（v1.0） GitHub 仓库

01为什么被保护的资源包打不开

被保护/混淆的资源包其实并没有真正加密：它们的中央目录与本地文件头元数据互相矛盾（文件名被改写、大小/CRC-32 被修改、伪目录条目、伪造的 EOCD 签名）。严格校验的解压软件——7-Zip、WinRAR、Windows 资源管理器、Python 的 zipfile——会拒绝它们，而 Minecraft 依然能正常读取，因为 java.util.zip.ZipFile 信任中央目录。某些混淆器还会进一步破坏文件内容本身（PNG 块 CRC-32 / IDAT Adler-32、Ogg 头部字段、被压缩成单行的 JSON），即使重建容器，提取出的文件也打不开。

02功能

  • 检查——全面检测：条目数、本地头与中央目录元数据差异（文件名、大小、CRC）、伪目录、伪造 EOCD、数据 CRC-32 校验、无法读取的条目——并给出 完好 / 疑似混淆保护 / 已损坏 的结论，同时检测 PackSquash 混淆（被混淆的 PNG、Ogg、JSON）。
  • 修复（反混淆）——通过 ZipFile + ZipOutputStream 重建干净压缩包；输出的压缩包任何解压软件都能打开。它还会修复被 PackSquash 混淆的 PNG / Ogg / JSON 内容，让提取出的文件真正能显示和播放。
  • 混淆——修复的逆操作，参数可调：改名方式、比例、伪装目录、白名单、伪 EOCD、CRC 扰动、随机种子，以及对 PNG / Ogg / JSON 的内容混淆。

03使用方法

java -jar mcpack-deobfuscator.jar                              # 图形界面（检查 / 修复 / 混淆）
java -jar mcpack-deobfuscator.jar -check <输入.zip>
java -jar mcpack-deobfuscator.jar -repair <输入.zip> <输出.zip>
java -jar mcpack-deobfuscator.jar -obfuscate <输入.zip> <输出.zip> \
      [--name <none|upper|digit|random>] [--percent <0-100>] \
      [--fake-dir <0-100>] [--eocd] [--crc] [--no-sizes] \
      [--content] [--seed <n>] [--whitelist <a,b,c>]

界面语言跟随系统（中文 / 英文）；命令行输出为英文。需要 JDK 8+。
